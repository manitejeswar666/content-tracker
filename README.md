# Content Pipeline Tracker

Track content ideas from Idea to Published, with a five-stage board.

**Live:** https://content-tracker-sand.vercel.app

## Built with
- React + Vite
- Plain CSS (studio-inspired editorial theme)
- localStorage for persistence

## Features
- Five stages: Idea, Script, Shoot, Edit, Published
- Add, delete, and move items between stages
- Edit a title in place by clicking it
- Board is saved in the browser, so it survives a refresh
- Responsive layout
